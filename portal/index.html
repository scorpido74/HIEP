Architecture & security

Principles first, documentation next

HIEP is being developed from explicit architecture and security principles. The principles are available today; detailed architecture and security documentation is the current next step.

Available

Architecture principles

Fifteen principles guide HIEP across identity, explicit verification, least privilege, lifecycle, trust, resilience, observability, and data protection.

View architecture principles

In development

Architecture documentation

Detailed HIEP architecture documentation will describe context, requirements, logical and physical architecture, trust relationships, resilience, observability, and architectural decisions.

Available

Security principles

Security is embedded in the current architecture principles through explicit verification, least privilege, phishing-resistant authentication, minimal trust, failure handling, and auditability.

Explore security principles

In development

Security documentation

Dedicated security documentation will cover security objectives, assets, trust boundaries, threats, controls, authentication, authorization, identity lifecycle, audit, resilience, and residual risks.
